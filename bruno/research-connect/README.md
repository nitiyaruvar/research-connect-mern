# Bruno collection

Open this folder as a collection in Bruno and select the `local` environment. Start the API and MongoDB first. Use `Register` and `Login` to obtain a development token; paste it into the secret `token` variable in your local Bruno environment. Never commit a real token, password, or provider credential.

The upload request accepts a base64 data URL. Replace its placeholder with a small, public PNG/JPEG/WebP/PDF data URL before sending. Upload URLs are public; do not use confidential material.
